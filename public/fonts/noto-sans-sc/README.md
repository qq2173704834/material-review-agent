# Noto Sans SC local font assets

Downloaded 2026-11-15 from Google Fonts CSS API (Noto Sans SC v41), requested weights 400/500/600/700 and display=swap:

https://fonts.googleapis.com/css2?family=Noto+Sans+SC:wght@400;500;600;700&display=swap

101 shared WOFF2 Unicode subsets, 4,593,300 bytes in total. The CSS family alias is Study Sans. See src/app/fonts.css for Unicode ranges. Browsers request only the subsets needed by the page; runtime requests are served from /fonts/noto-sans-sc/ on the same origin. font-display: swap and a system-font fallback keep text available if assets cannot load.

Fonts are unmodified. The SIL Open Font License 1.1 is included in OFL.txt, retrieved from:

https://github.com/google/fonts/blob/main/ofl/notosanssc/OFL.txt

No external font host is required at runtime.
