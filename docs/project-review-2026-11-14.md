# ENG-047 / ENG-048 自主审视与优化记录

日期：2026-11-14。用户授权离开期间自主检查、修改交互、增加报名截止提醒并扩充考试和证书信息。以下按实际检查和交付记录，不将88条统一规划改为全部完成。

## 本轮修改

1. 报名截止提示在首页卡片、考试中心列表、公告详情及个人收藏复用。精确时刻按北京时间显示剩余天/小时/分钟，临近24小时突出；只知道日期时只显示日历天数，不补造23:59。取消、延期、撤回不继续显示正常倒计时。每30秒及窗口重新获得焦点时更新，状态点同步更新。
2. 成绩公告显示“成绩查询/待公布成绩”，不再一律显示报名时间待确认；没有报名截止信息的成绩公告不展示无意义的报名提醒。
3. 首页优先当前考试；无当前项目时默认选择有内容的“考试临近”，再回退“最近更新”。用户指定的子标签保持不变，不把历史公告冒充当前可报名。采集诊断折叠为更新详情。
4. 个人中心将“我的考试目标”移到身份信息后，补充无目标引导；已撤回公告的收藏不继续显示可报名。
5. 手机导航保留文字，助手关闭时仅显示卡通图标、保留无障碍名称；普通用户不再看到无权限的内容管理入口，管理员仍可见。服务端权限检查保持有效。
6. 原文可显式标为“摘录”，详情说明非全文，避免把部分条款当成完整资格规则。
