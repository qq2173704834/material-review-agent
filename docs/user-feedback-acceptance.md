## 数据与兼容

平台 SQLite 版本由 5 迁至 6，新增按用户保存的 `assistant_preferences`，不删除原表或业务记录。未配置的新用户默认允许生成；明确关闭后持久生效，旧客户端未传该字段时保持原设置，显式单次 `allowExternal: false` 仍可限制外部处理。对话保存与外部AI处理保持独立含义。

所有测试使用独立端口、独立数据目录及合成账号/公告/文件，不改真实用户数据，不读取或输出环境密钥。原工作区 `next.config.ts`、`src/instrumentation.ts`、`tsconfig.json` 三个既有修改不包含在本次提交。不推送、不部署。
