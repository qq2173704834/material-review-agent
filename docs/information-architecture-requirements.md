# 功能分区与统一日程重组需求

日期：2026-11-15（Asia/Shanghai）。登记任务ENG-094。用户反馈日程、考试等信息杂乱，认可上一轮提出的五个主入口、校园通知与私人日程分离、考试目标与具体安排分开管理的方案，要求整理成需求。

本批为ORG-01—10共10组40条验收条件，全部待实施。本轮仅落盘需求与计划，不修改应用代码、路由、数据库或真实记录。现有功能可以复用，但现有回归通过不能作为本批页面重组已完成的证据。

## 已确认的产品结构

| 主入口   | 页面职责                                             | 主要操作与边界                                                                                        |
| -------- | ---------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| 首页     | 近期考试、本校重要通知及本人近期事项的紧凑摘要       | 发现信息、继续准备、进入对应完整列表；不铺满日历和目标详情                                            |
| 考试中心 | 全国、地区考试及证书的公共信息                       | 搜索、了解条件/场次、看公告、加入备考；不混入私人作业和校内课程考试                                   |
| 校园通知 | 所选学校公开发布的教务、竞赛、奖助、活动、就业等通知 | 阅读、收藏、查看原文、选择节点加入日程；不直接展示本人的全部日程                                      |
| 学习资源 | 考试与公共课程资料、练习和学习方法                   | 查找、阅读、收藏及围绕目标学习；不承担考试通知或作业截止的主列表                                      |
| 我的备考 | 个人目标和安排的管理区                               | 分成“考试目标”“我的日程”“学习记录”三个独立子页面，默认进入考试目标；材料自查收纳到目标/事项和个人工具 |

“我的备考”的三个子页面采用稳定导航并各有可直接访问的地址，不在同一长页面堆叠完整模块。“考试目标”承接长期准备，“我的日程”承接具体节点，“学习记录”沿用真实学习和完成记录。全站当前用户与退出登录选项继续保留。

## 对象与操作约定

| 对象         | 例子                                   | 本次约定                                                         |
| ------------ | -------------------------------------- | ---------------------------------------------------------------- |
| 公共考试信息 | 四级考试介绍、某场报名公告             | 供浏览和查询；收藏信息、加入备考是清楚区分的操作                 |
| 考试目标     | 我准备参加某场四级考试                 | 保留个人地区/场次/科目等选择，关联路线、资料、学习记录和材料准备 |
| 具体日程节点 | 四级报名截止、笔试、高数期末、报告提交 | 统一按本人关系聚合；明确日期进入正常日程，未知日期进入待公布区域 |
| 校园公开通知 | 学校发布的奖学金申请通知               | 阅读本身不创建私人事项；用户选择报名/提交等节点，核对后加入日程  |
| 私人导入     | 班级群收到的作业通知或考试截图         | 经本人预览确认后创建私人事项，不自动发布到全校通知或公共知识库   |

同一对象使用稳定关联。全国考试目标中的公开日期可以投影到统一日程，首页和目标页展示其摘要；不为每个页面另存一份独立日程。通知更正、用户手动调整、目标取消等行为需要保持各自含义。
