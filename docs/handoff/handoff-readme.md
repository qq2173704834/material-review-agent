# 在另一台电脑继续开发

整理日期：2026-11-11。

## 最简单的使用方法

1. 将 handoff-prompt.md 复制到另一台电脑。
2. 在新电脑上选择准备开发的项目目录，并打开你的 AI 编程工具。
3. 让工具读取 handoff-prompt.md 全文；也可以直接复制其全文作为新会话的第一条消息。
4. 告诉它当前项目目录，以及你希望这轮先做什么。如果直接执行提示词，默认从环境检查、规则落盘、开发计划和工程初始化开始。

可发送：

```text
请完整阅读 handoff-prompt.md，按其中已确定的项目规则接手开发。
使用我当前打开的工作目录。先检查环境和已有文件，落盘项目规则与需求清单，
然后按功能推进工程初始化和最小审查闭环。需要补充的信息集中提出，
已经确定的技术方向、命名规范和 commit 格式直接沿用。
```

如只想继续完善规则或设计，可改为：

```text
请完整阅读 handoff-prompt.md，恢复项目上下文。
本轮先整理首版范围和页面设计，暂不开始业务代码开发。
```

## 文件说明

- handoff-prompt.md：可独立使用的接手提示词，内嵌全部 114 条需求与 12 个验收场景。只带走它也能接手。
- requirements.md：独立的需求与验收清单，方便查阅。
- project-rules.md：现阶段开发规则与已选提交模板。
- stage-summary.md：阶段总结、比赛依据与待定事项。
- handoff-readme.md：本文，迁移使用方法。

优先读取 handoff-prompt.md。其他文档为参考快照，不必重复将其全文输入模型。它们提到的原会话文件状态不是新电脑现有项目的事实，新助手应先检查实际目录。

本包只包含文本资料，没有应用代码、依赖、API 密钥、测试结果或部署产物。比赛日期为 2026-11-11 整理时的历史信息，执行时需按实际日期核实。
