## 产品定位与用户意图

用户希望网站以考试信息为主：登录后首页展示近期热门考试并每日更新；右下角提供卡通形象AI助手，基于知识库解答考试和学习问题；学习子页面依据用户考试需求推荐资源、资料和资讯；原材料自动预审转为个人界面内较小的子功能，结合用户目标与数据库考试信息提供自动预审。

产品描述暂为“面向在校学生的考试信息与学习服务平台”，正式名称、卡通形象和品牌后续再定。保留用户名+密码登录与现有数据隔离。主路径为：登录 → 看近期考试/搜索考试 → 设定我的考试目标 → 获取学习资源与AI答疑 → 个人中心准备报名材料 → 辅助预审及整改。

本轮仅形成待办需求，未授权此轮代码实现、部署或自动采集。此前EXP-01—EXP-08的8组32条继续纳入待办，目录扩充为本方向的基础。本文件只补充产品组织与新交互，不重复统计原认证、公告、收藏、预审引擎的旧验收条件；本轮新增条件必须按新场景重新验收。

## 页面与能力关系

| 页面/入口    | 面向用户的主要内容                                        | 与既有功能的关系                               |
| ------------ | --------------------------------------------------------- | ---------------------------------------------- |
| 登录/注册    | 用户名密码认证、恢复及登录回跳                            | 复用已有认证，成功登录默认进入信息首页         |
| 首页         | 近期重点/热门、报名及考试节点、今日更新、我的目标快捷入口 | 重组主入口，不把任务管理列表当默认首页         |
| 考试中心     | 分类目录、搜索、考期地区、公告与官方入口                  | 沿用既有考试平台并承接EXP扩充                  |
| 学习         | 按目标展示资料、公开课、考试大纲、练习、备考资讯          | 新增资源目录与推荐，资源范围按实际接入         |
| 右下角AI助手 | 考试咨询、学习答疑、页面上下文和相关入口                  | 新增知识库问答，不沿用旧审查模型测试冒充验收   |
| 个人中心     | 考试目标、收藏、节点与站内提醒、资料收藏、材料准备与预审  | 汇总个人考试过程，预审作为目标下的次级功能     |
| 管理后台     | 官方来源、知识条目、资源审核、首页精选、更新与异常        | 复用管理员角色并扩展内容治理，普通用户不可访问 |

需求优先级P0为信息可信、目标建立、基础资料与问答及原功能迁移；P1为个性化、对话持久化、可控自动执行与使用评价。优先级是建议，不代表已经安排编码批次、技术选型或交付日期。

## 分组需求与验收条件

所有条目的当前状态为**待实施**，文档形成不代表功能完成。

### PORT-01 首页定位与导航重组（P0）

- PORT-01.A1：登录成功且没有有效站内回跳目标时进入考试信息首页；从受保护详情页登录后回到原详情。访客业务门禁继续有效，不因为首页调整开放用户数据。
- PORT-01.A2：主要导航提供首页、考试中心、学习、个人中心；管理员内容管理作为管理入口。材料预审归入个人目标的“材料准备/预审”，首页不要求用户先创建审查任务。
- PORT-01.A3：保留旧任务/公告/报告深链接及通用材料审查入口；导航调整不删除历史数据，历史任务不强行绑定错误考试，品牌名称与图形资产后续确认。
- PORT-01.A4：手机、桌面及键盘均能完成找考试、进入学习、呼出助手及个人材料预审；主内容、返回路径和当前位置明确，首页信息密度通过学生走查验证。

### PORT-02 近期考试与热门信息首页（P0）

- PORT-02.A1：首页提供近期重点、报名中/即将截止、考试临近及最近更新等分区；近期范围和展示量可调整，只有已审核且有依据的内容进入正式信息流。
- PORT-02.A2：卡片显示考试名、考期、地区、关键节点、信息来源及最近核查时间；全国公告与学校/地区安排分开，未知日期、延期和取消有真实状态。
- PORT-02.A3：热门排序有可解释依据，可采用匿名聚合关注量与管理员精选；精选需标注，不伪造浏览量/报名人数。数据不足时展示“近期关注/精选”，不包装成统计热榜。
- PORT-02.A4：用户可从卡片查看详情、设为考试目标或收藏；首页支持查看更多和合理的加载边界。缺数据、加载失败、过期与无匹配分别提示，不用虚构公告填满首页。

### PORT-03 每日更新与时效管理（P0）

- PORT-03.A1：正常运行的服务每天按Asia/Shanghai至少完成一次已启用来源的更新检查；时点可配置，既有更高频采集可保留。每日检查没有新公告时记录“今日检查无新增”，不伪造新增。
- PORT-03.A2：更新链路覆盖采集、重复去重、更正版本、草稿审核、正式发布及知识检索同步；内容未审核时保留草稿/待审状态，不承诺采集即公开或即成为确定回答依据。
- PORT-03.A3：分别保存来源检查时间、公告发布时间和审核更新时间；局部失败保留上次有效数据并标注延迟，管理端可定位失败来源、重试和待审积压。
- PORT-03.A4：停机、漏跑、重启和重复调度有幂等补查与执行记录；界面不将服务离线期间写成更新成功。正式全天运行所需主机和守护调度留待部署阶段落实。

### PORT-04 我的考试目标与偏好（P0）

- PORT-04.A1：用户可从目录/公告建立一个或多个考试目标，指定考试类型、地区、考期及必要的级别/科目；未确定考期可先关注，后续由用户补充或确认。
- PORT-04.A2：可选填写学习基础、备考阶段、可投入时间、目标分数、资源形式偏好和必要的专业/年级信息；非必要资料可跳过，不能为浏览资料强制上传证件。
- PORT-04.A3：目标支持编辑、暂停和归档；切换地区、考期或科目后推荐及节点重新匹配，不能把多个目标的日期、材料要求和学习进度混用。
- PORT-04.A4：显示当前生效目标及推荐依据；新用户可先浏览通用信息，清除目标/偏好能停止对应个性化，修改目标不删除历史收藏、任务或结果。

### PORT-05 考试与学习知识库（P0）

- PORT-05.A1：知识库收录经审核的考试公告、报考条件、考纲/科目、时间节点、官方常见问答及有授权的学习资源说明；每条保留来源、版本、适用范围、核查时间和可见性。
- PORT-05.A2：内容入库有解析、分类、索引、审核及撤回状态；网页和附件分别披露读取覆盖，不能把附件链接当作已读正文，个人审查材料默认不进入公共知识库。
- PORT-05.A3：问答检索按考试、考期、地区、科目及知识版本匹配；更正/撤回同步影响检索，旧版本可追溯，当前证据冲突时保留双方来源及待核实状态。
- PORT-05.A4：管理员可核对原文、维护条目、重建索引并查看失败记录；知识库技术、向量服务或本地检索方案后续设计，入库文本中的指令不能改变助手权限。

### PORT-06 卡通AI助手入口与对话体验（P0基础，P1历史）

- PORT-06.A1：登录后的主要业务页面右下角有统一卡通助手入口，点击展开对话面板，可最小化/关闭；手机布局不遮挡提交、分页和预审证据，键盘可操作、焦点可返回入口。
- PORT-06.A2：提供考试咨询、学习答疑和当前目标的示例问题；仅在用户允许时带入当前页面/考试目标，跨页不丢失进行中的对话，不自动读取私人文件正文。
- PORT-06.A3：对话呈现发送、生成、取消、失败和重试状态；连续点击不重复提交，取消前已发生的耗用如实记录，未知费用不写为零。服务未配置/超限时解释原因，模拟回答必须可识别，不冒充真实知识库查询。
- PORT-06.A4：用户可新建、查看和删除本人会话，选择不保存或清除历史；卡通形象使用自有/获授权资产，支持减少动态效果，不依赖语音、3D或持续动画才能使用。

### PORT-07 基于知识库的考试咨询与学习答疑（P0）

- PORT-07.A1：报名时间、报考条件、考试内容和材料要求等事实回答优先使用对应范围的已审核知识，给出可点击来源、原文证据和核查时间；不能仅靠模型记忆生成当前日期和政策。
- PORT-07.A2：考试/地区/考期不明确且影响答案时集中澄清；检索无结果、仅旧版资料或来源冲突时明确范围与未知，提供官方查询入口，不编造引用或确定资格结论。
- PORT-07.A3：支持学习概念解释、知识点梳理、基于已接入资料的练习讲解和备考建议；区分官方考试规定、资料内容与AI学习建议，生成练习标为生成，不伪称官方真题。
- PORT-07.A4：回答可关联考试详情、匹配资源、我的目标或材料准备入口；允许反馈过期/错误答案并保留对应来源版本供复核，不能未经用户操作代报名、提交材料或触发付费审查。

### PORT-08 学习资源与资料子页面（P0）

- PORT-08.A1：学习页按当前考试目标展示考纲、公开课/课程入口、学习资料、练习及备考资讯；用户可切换目标、搜索和按科目、阶段、资源形式筛选，没有目标时可浏览通用目录。
- PORT-08.A2：资源卡及详情显示名称、来源/作者、对应考试和版本、适合阶段、格式、语言、免费/付费及最近核查时间；未知费用或不可公开下载时如实说明。
- PORT-08.A3：资源保留原始地址和使用授权；仅有外链授权时跳转原站，失效/过期/被撤回时提示并可反馈，不收集未授权的付费资料或考生个人数据。
- PORT-08.A4：用户可收藏、取消收藏和标记已看/不感兴趣，资源与资讯分别识别；重复资源合并依据保留，不能把是否打开页面自动解释为学习完成或能力达标。

### PORT-09 根据考试需求推荐学习内容（P1）

- PORT-09.A1：依据用户明确目标、科目、备考阶段和可选偏好匹配资源与资讯；推荐说明具体理由，当前考期与教材/大纲版本不一致时提示，不混入其他考试材料。
- PORT-09.A2：支持多个目标独立推荐；无历史行为时按目标及审核质量提供默认结果，不要求用户先积累行为，也不伪造精准匹配分数或录取/提分概率。
- PORT-09.A3：用户可调整偏好、隐藏资源、减少同类推荐或关闭个性化；同一条资源/资讯避免反复推送，来源变化和重新推荐保留可解释依据。
- PORT-09.A4：本批“推送”默认指学习页推荐流和站内更新提示；邮箱、短信、浏览器系统通知或其他外部渠道需另行明确，不将用户登录视为外发授权。

### PORT-10 个人中心与备考进度（P0）

- PORT-10.A1：个人中心汇总我的考试目标、收藏公告、学习资源、近期节点和材料准备入口；用户可看各目标待办，材料预审作为目标下子功能，不占据首页主流程。
- PORT-10.A2：站内提示覆盖已确认的报名/考试节点、收藏公告更正、目标资源更新及预审待处理问题；未知时间不生成倒计时，延期/取消能撤销旧提示并说明原因。
- PORT-10.A3：用户可标记学习/材料待办进度、已读提示和暂停关注；个人进度是用户记录，不直接改变审查判定或证明考试资格、报名成功。
- PORT-10.A4：所有目标、偏好、收藏、资源进度、会话与材料按账号隔离；退出、会话失效、换号及注销沿用既有边界，管理员不能默认浏览私人学习对话或材料。

### PORT-11 基于考试信息的个人材料预审（P0）

- PORT-11.A1：从个人考试目标进入材料准备，自动带入用户确认的考试/地区/考期和已审核公告版本；有岗位/阶段等影响要求时需明确选择，无法确定时保留待补充。
- PORT-11.A2：根据公告正文及已读取附件提取材料清单和独立要求，展示原文依据、未读附件和冲突；用户无需重复粘贴已确认数据库公告，通用任务仍可自行导入来源。
- PORT-11.A3：结合用户主动提供的背景和材料，复用既有完整性/规格/一致性与证据审查能力；没有文件或关键信息时列缺项/待确认，不能直接宣布报名或官方资格审核通过。
- PORT-11.A4：个人中心展示按考试归属的材料清单、五类结果、证据、整改及复检入口；历史快照和报告可回看，旧通用任务未绑定时仍可访问，不自动删除或错配。

### PORT-12 自动预审触发与执行控制（P1）

- PORT-12.A1：用户可对具体目标开启、暂停和关闭自动预审，首次说明触发时机、材料范围与可能模型耗用；未开启时保留手动预审，不因看首页、打开助手或修改普通偏好自动运行模型。
- PORT-12.A2：在用户已开启且所需背景/来源已明确时，上传完成、替换/修订相关材料触发受影响项的受控复检；按材料与规则版本合并重复事件，已有执行不并发重复启动。
- PORT-12.A3：数据库公告更新时先提示变化并使旧结果待复核，用户明确采用适用新版后再按开关执行；阶段/地区变化、来源冲突、附件未读或材料缺失时优先请求必要补充，不自动覆盖人工规则。
- PORT-12.A4：自动执行有配额、频率、并发、取消和失败重试边界，展示上次实际执行时间/原因/版本及耗用；超限或失败保留任务和已保存材料，不把执行成功等同所有项通过。

### PORT-13 内容、隐私与模型服务治理（P0）

- PORT-13.A1：官方事实、人工精选、AI摘要、AI练习、学习建议及外部资源明确标识；发布、撤回、反馈处理和知识库更新有角色、时间及依据记录，商业资源不得伪装成官方推荐。
- PORT-13.A2：助手只访问当前用户授权范围，私人对话、背景和材料不进入全站知识库、不供其他账号检索；涉及外部模型时说明发送范围并提供必要设置，密钥沿用服务端环境配置。
- PORT-13.A3：问答和自动审查分别记录次数、Token/费用可知范围、失败与超限，配置限额及停用入口；服务中断时官方信息和已存学习资源仍可访问，不以虚假回答掩盖失败。
- PORT-13.A4：来源文章、知识文本和附件视为待处理数据，不能指示助手泄露系统提示、其他用户信息或执行工具命令；答案引用和跳转校验来源范围，处理不可信链接沿用既有防护。

### PORT-14 验收、兼容与真实效果（P0）

- PORT-14.A1：新主流程验收覆盖首次登录首页→设目标→看资料→有来源AI咨询→个人材料预审；分别验证手机/桌面、键盘和助手遮挡情况，既有任务/收藏/账号不回归。
- PORT-14.A2：每天更新用可控时钟/来源验证无新增、重复、更正、撤回、失败、停机和补查；热门冷启动及低数据量有真实展示，不靠插入虚假热度通过验收。
- PORT-14.A3：知识问答用独立可追溯样例验证引用、日期/地区正确性、未知/冲突处理、学习建议标识及账号隔离；模拟接口与真实模型分别记录，效果门槛后续按样本确认，不承诺固定准确率。
- PORT-14.A4：推荐与自动预审覆盖多目标、不感兴趣、关闭个性化/自动开关、重复触发、限额和旧版本复检；每条状态关联实际证据，原始114条或CAP/REL通过不能替代这56条验收。
