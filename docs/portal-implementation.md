# 考试信息与学习平台实现记录

更新：2026-11-14。对应 ENG-038—ENG-043，EXP/PORT 共88条条件。本文区分实现、已执行验证与剩余条件，不宣布全部关闭。

## 当前实现

- ENG-038：68类目录（原29类+39候选）、分组和别名搜索、考试性质与资格范围提示、18个官方查询入口；新增采集来源默认关闭，历史来源、收藏及版本不覆盖。综合机构公告按明确考试名分类，专业/计算机四级与CET分开。
- ENG-039：登录后考试/学习首页，近期节点、报名时段、考试临近、截止与最新公告；热门仅使用至少3账号实际收藏。个人中心多考试目标、地区考期科目、学习基础/阶段/时间/分数/形式偏好、进度、暂停及归档；历史任务迁到 `/tasks`。
- ENG-040：学习页多目标推荐、科目/阶段/形式筛选、收藏/已看/隐藏、个性化开关；默认18条官方查询导航，不冒充课程、教材或当期安排。知识/资源/高校参考版本化草稿、审核发布、撤回；未发布修订不替换已发布快照。发布校验真实公开HTTPS及跳转范围。
- ENG-041：自有SVG卡通助手、桌面/手机对话、键盘关闭返回焦点；私有会话、取消、幂等、20问/小时与关闭保存。考试事实查询已审核公告/知识，提供原文、范围、版本和核查时间。学习答疑独立标识AI建议。真实模型须明确同意发送问题及公开知识；私人材料不进入公共检索。无证据/仅历史/范围不明时澄清。
- ENG-042：从目标带入已审核公告正文建材料任务；原规则提取、材料上传、证据/整改/复检及报告复用。自动预审默认关闭，逐目标明确授权；每分钟检测材料/规则快照，重复合并，每账号滚动24小时最多5次，单进程串行，执行本身180秒限时。公告新版先暂停自动条件，用户明确采用后重新核对规则。未读附件、无材料、无当前规则或未知考期不运行。支持关闭/取消及手动检查条件，不把未执行或执行完成算全部通过。
- ENG-043：每日检查按北京时间记录，无启用来源、失败、未完成与完成分别披露；可设置每日补查小时，保留原更高频来源间隔。新增内容仍需审核。内容反馈仅提交用户明确选择的内容与引用版本，管理员处理，个人中心可见处理结果。

## 尚需完成或独立验收

- 本地主要流程和上述检查通过；逐条88项证据映射、每日更新可控时钟/复杂冲突、更多自动触发与真实模型专项覆盖尚未全部完成，功能组仍在开发/验收中。
- 18个入口可读不等于每个来源列表/详情适配成功。新增候选的官方资格依据、状态、级别/有效期及逐源真实采集须继续核验，不能宣称68类均已接入或可报考。
- 当前真实学习内容主要是管理员录入与官方导航；更多合法课程/考纲/练习需按授权及适用版本维护，不凭空填充资料量。
- 复杂来源冲突、独立真实模型回答质量、推荐质量、长期每日调度与停机恢复仍需专项证据；模拟通过不代表真实模型效果通过。
- 自动执行为本地单服务模式，跨进程/多实例调度未验收；中断超过5分钟的在途记录标失败而不隐式重试，用户可手动复检。全天运行、主机守护和公网环境不在本轮部署范围。
- 用户主流程走查、完整辅助技术审计、正式品牌/形象偏好和独立业务质量验收保留待验收。
