# ENG-112 介绍文档字体与分页修订

用户在WPS中发现标题字形不统一、缺失字体提示、图3题注独占第3页，以及技术页难以理解。原有LibreOffice渲染8页不能证明WPS排版一致，旧稿在用户WPS中为9页。

## 修改

- 统一文档、样式、关联字符样式和主题字体为本机已安装的微软雅黑，移除标题残留的主题字体与字距设置，关闭继承斜体。标题、副标题、正文和题注保留字号层级。
- 调整两幅材料自检截图尺寸，图片与题注保持同页；明确正文行距并关闭按文档网格吸附，给跨软件分页留出空间。
- 技术页改为技术及用途对照、AI如何参与材料自检、三步验证与简短结果。保留关键技术和AI测试内容，详细运行记录仍随源码提供。
- 原稿和视频保留。后续结合ENG-113评委材料清理，新版统一放outputs/submission-judge-review-2026-11-17，配套介绍Markdown和作品包同步更新。

## 验证与范围

新版通过LibreOffice渲染为8页，已逐页查看8张PNG，无溢出或题注单独占页。XML检查确认字体引用已统一且无残留主题字体属性，图3与其题注在渲染第2页。两个ZIP通过CRC、视频一致性和预设凭据模式检查，具体数量与SHA256见本轮打包报告；后续依赖修复完成后重建最终源码包。

WPS自动检查未完成：两个桌面工具入口均在初始化时返回“failed to write kernel assets: 系统找不到指定的路径”。本轮不将LibreOffice结果表述为WPS实测通过，用户后续以WPS打开新版确认。

本轮仅文档修订，未重新运行应用测试；未上传、提交、推送或部署，不增加模型调用，不关机。已有三个应用配置改动保持原样。
