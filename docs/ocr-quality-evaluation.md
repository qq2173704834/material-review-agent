# OCR区域核对与独立质量评估

日期：2026-11-14。ENG-033 / CAP-01、CAP-02。

任务准备页的材料卡 →“核对与修订解析文字”→“图像区域、阅读顺序与增强核对”，可以对照当前版本页图与所选文字区域。OCR区域先标为候选；区域类型、阅读顺序、印刷/手写类别及表格行列/合并/续表由核对者确认。确认、修订或增强均形成新材料版本，历史页图和原件保留，旧执行按版本待复检。文字修订会撤销该区域确认。候选单元格仅按OCR间距推断，不能冒充可靠合并/续表恢复；跨页关联须指向同材料更早页已确认的同一表格，行号跨页连续，重叠关系拒绝。

图像增强支持旋转、对比度/局部阴影、锐化和手动四角透视候选。四角按左上、右上、右下、左下的归一化坐标填写，交叉/退化形状拒绝。可先预览并放弃，明确采用才重新OCR；原件不替换，处理参数随解析版本保存。不能复原失焦、遮挡或不存在的信息。

通用Tesseract中英引擎继续用于印刷和手写候选，**没有增加专用手写识别模型**。人工分类不等于手写质量已过关。姓名、证号、日期、金额等候选字段不能由页面平均分自动确认，印章存在候选不判断真伪。预算确定性合计仍仅接受完整CSV/XLSX，不把OCR行或人工局部修订当完整可靠单元格。

## 独立标注输入

`pnpm evaluate:ocr 本地标注集.json 新报告.json`只读取本地文件，报告不得覆盖已有文件。样本需明确来源/授权、标注者、材料类型和实际耗时，不能把工程合成参考标成独立金标准。最多1000份样本、每份200个区域/200个关键字段，每区域2000字符，输入20MiB上限。

```json
{
  "format": 1,
  "labelOrigin": "填写真实独立标注组织方式",
  "samples": [
    {
      "id": "脱敏样本编号",
      "category": "handwritten",
      "source": "填写授权样本来源",
      "authorization": "填写授权或公开许可依据",
      "annotator": "填写真实标注者标识",
      "elapsedMs": 1200,
      "regions": [{ "reference": "人工原文", "prediction": "实际OCR输出" }],
      "keyFields": [{ "name": "姓名", "reference": "人工原值", "prediction": "实际识别值" }]
    }
  ]
}
```

分类分别为`printed`、`complex_layout`、`low_quality`、`handwritten`。区域遗漏必须在reference中保留，将prediction留空；不能删除失败样本。报告按分类保存样本数、参考字符数、编辑错误数、区域数/整区漏读数、关键字段数/逐字命中数、累计耗时及派生指标，附数据集SHA-256和逐样本原始计数。CER只做NFC规范化，不去空白；关键字段完全逐字比较。整区漏读率不能当成所有漏字率，CER同时计入删除错误。

当前仅验证计算工具与工程合成样例；没有真实独立手写/低质量材料标注集，尚未提出经业务认可的数值门槛，故CAP-02.A4与原OPT-09人工效果条件保持待验收。报告不会自动生成“质量通过”结论。建议先固定四类各自的基线，再由业务确认姓名/证号/日期/金额的精确匹配门槛及可接受漏读率。
