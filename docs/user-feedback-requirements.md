## UXR-01 考试卡片间距与布局修正

- 优先级：P1；状态：待实施；关联缺陷：BUG-039；关联原需求：PORT-01.A4、PORT-02.A1。
- 用户反馈：截图中相邻考试卡片边缘贴合、存在重叠观感，需要调整位置。
- 证据：[用户截图](assets/feedback/exam-card-overlap.png)。截图可确认卡片之间缺少清楚的留白，红框处边缘/圆角相互挤压；是否由卡片宽度、列间距、阴影或其他布局规则导致，实施时复现确认，不预先认定根因。
- 目标：卡片各自独立，标题、分类、状态和底部操作清晰可见；随可用宽度调整列数，保持现有卡片内容与操作。

| 条件      | 具体需求与验收标准                                                                                                                                        | 状态   |
| --------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| UXR-01.A1 | 调整卡片宽度与行列间距。桌面端卡片之间建议至少16px留白、移动端至少12px；相邻卡片边框与圆角不接触、不覆盖，阴影不形成重叠边框观感。                        | 待实施 |
| UXR-01.A2 | 按容器宽度调整列数，窄屏自动减少列数或单列展示；在390、768、1280、1920px视口及浏览器125%/150%缩放下，卡片不重叠、不越出容器，不产生由卡片引起的横向滚动。 | 待实施 |
| UXR-01.A3 | 使用长考试名称、长标题、多行摘要和不同状态文本核对：分类与状态不互相遮挡，文字留在卡片内；“查看详情”“关注目标”可见可点击，键盘焦点不被相邻卡片遮住。      | 待实施 |
| UXR-01.A4 | 对截图所在考试列表及复用同类卡片的首页列表进行回归，检查单卡、多卡、跨行和筛选后布局；保存修正前后截图并人工核对用户标注区域，才能标记完成。              | 待实施 |

实施建议：优先检查网格间距、卡片最小宽度、内容溢出和阴影；采用随容器变化的布局规则，避免仅固定移动某一张卡片。具体技术方案在复现后确定。

本条反馈作为PORT-01.A4学生走查发现的问题记录，当前不构成该项通过；修正后继续收集首页体验反馈。

## UXR-02 普通用户界面移除本地环境入口

- 优先级：P1；状态：待实施；关联原需求：PORT-01、PORT-13；属于产品角色与导航调整。
- 用户反馈：面向学生的界面不应展示“本地环境”菜单和开发配置内容。
- 证据：[用户截图](assets/feedback/local-environment-navigation.png)。页面包含运行模式、开发状态、模型API配置与本地环境说明。
- 目标：学生只看到考试、学习、个人目标与材料预审等业务功能；配置和诊断能力保留在管理员维护入口。

| 条件      | 具体需求与验收标准                                                                                                                                                                                              | 状态   |
| --------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| UXR-02.A1 | 从普通用户桌面侧栏、手机导航及业务页跳转中移除“本地环境”入口，包括材料预审中的“前往本地环境”提示。普通用户不再看到本地路径、环境文件、启动命令、模型连接测试和内部开发验收清单。                                | 待实施 |
| UXR-02.A2 | 环境配置状态及模型测试归入管理员维护区域，页面和相关配置/诊断API均由服务端检查管理员权限；普通用户直接访问旧/setup或调用诊断接口也不能读取维护信息或触发连接测试。实现时核对现有统一认证门禁，不仅隐藏菜单。    | 待实施 |
| UXR-02.A3 | 模型服务未配置或不可用时，业务页显示“AI服务暂不可用，请稍后重试或联系管理员”等可理解提示；保留用户输入、材料及其他可用功能，配置问题交由管理员处理，不引导普通用户编辑环境文件或启动服务。                      | 待实施 |
| UXR-02.A4 | 对用户有意义的隐私说明、必要的功能限制及实际模拟结果标识，保留在对应功能内并使用简明业务语言；管理员仍可查看运行状态。用普通用户/管理员两种角色核对桌面、手机、直接URL访问及API权限，确认账号设置仍可正常使用。 | 待实施 |

实现排查位置：src/components/app-shell.tsx、src/app/setup/page.tsx、src/components/task-workspace.tsx、src/components/review-execution.tsx、src/app/api/model/test/route.ts。以上仅为当前源码定位，权限行为和具体迁移方案待实施时验证。

## UXR-03 精简材料预审流程介绍

- 优先级：P1；状态：待实施；关联原需求：PORT-01、PORT-11。
- 用户反馈：“从要求到复检，每一步都有记录”四步流程介绍不应作为普通用户页面的常驻大区块。
- 证据：[用户截图](assets/feedback/review-process-overview.png)，包含导入要求、匹配材料、逐项核验、整改复检四张卡片和“流程规划”标签。
- 目标：材料预审页面聚焦创建任务、继续处理和查看结果，降低重复说明占用的页面空间；需要时仍能找到简单操作帮助。

| 条件      | 具体需求与验收标准                                                                                                                                               | 状态   |
| --------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| UXR-03.A1 | 普通用户材料预审首页移除常驻四步流程大卡片、“从要求到复检，每一步都有记录”标题及“流程规划”标签，释放空间给实际任务和操作。                                       | 待实施 |
| UXR-03.A2 | 将必要使用说明收纳到“如何使用”帮助入口或首次使用的简短可关闭指引，默认不展开四张大卡片；语言直接说明用户要做的操作，用户可随时再次查看帮助。                     | 待实施 |
| UXR-03.A3 | 保留实际任务中的操作步骤、执行进度、问题定位、整改和复检入口。五类预审结果及“未核验不算通过”等必要含义放到结果说明或对应操作处，不作为首页常驻长篇介绍。         | 待实施 |
| UXR-03.A4 | 核对新用户无任务、已有任务及手机/桌面场景：创建/继续任务入口清晰，用户可完成上传、审查和复检；移除介绍后无空白占位、残留编号或失效链接，卡通助手不遮挡主要操作。 | 待实施 |

实现排查位置：src/components/review-task-home.tsx。四步图示作为使用帮助处理，不要求移到管理员后台；运行配置按UXR-02另行处理。

## UXR-04 我的考试页面信息精简与分层

- 优先级：P1；状态：待实施；关联原需求：PORT-04、PORT-10、PORT-11。
- 用户反馈：个人页面连续展示多个空模块和技术说明，很多内容不适合直接展示给普通用户，需要精简。
- 证据：[用户截图](assets/feedback/my-exams-information-clutter.png)，涉及“我的内容反馈”“收藏的学习资料与更新”“材料预审执行提示”“历史与通用材料预审任务”“我的考试时间节点 · Asia/Shanghai”“我的收藏”“关联预审任务”。
- 目标：我的考试默认聚焦当前考试目标、近期日程和下一步行动；次要记录有入口但不常驻堆叠，技术性描述改为用户能理解的提示。

| 条件      | 具体需求与验收标准                                                                                                                                                                                                                                                                                          | 状态   |
| --------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| UXR-04.A1 | 重组个人页面：主区展示当前考试目标和近期日程，收藏考试/学习资料合并至“我的收藏”子标签或子页面并按类型区分；反馈记录收纳到“我的反馈”入口。预审状态归属具体考试目标，通用及历史预审任务收纳到“材料预审”入口，取消“执行提示”“关联预审任务”等重复常驻区块。已有反馈、收藏、任务及更新提醒仍可查找，不删除数据。 | 待实施 |
| UXR-04.A2 | 无目标、无日程时提供简短空态和明确入口，如“还没有考试目标，去选择考试”；反馈、资料、预审无记录时不分别占用大块区域，次要入口可保留数量。仅对当前用户有实际待办或更新时显示紧凑提醒，避免连续多段“暂无”与零数量大标题。                                                                                      | 待实施 |
| UXR-04.A3 | 标题“我的考试时间节点 · Asia/Shanghai”改为“考试日程”等简明名称，必要位置统一标注“北京时间”；移除常驻的内部机制说明。无日期写“时间待公布”，不虚构日程；“提醒已读不表示完成报名”等说明按操作需要收纳到帮助或相应提醒中，不能让已读显示成已报名。                                                              | 待实施 |
| UXR-04.A4 | 用当前用户的空数据、多考试、多收藏、资料更新及预审处理中等场景核对桌面和手机布局：目标与日程易找，次要入口可访问，链接准确，账号隔离保持有效；收藏查看/取消、反馈状态查看、资料更新查看、历史预审及继续任务均可完成，保存重组前后截图核对。                                                                 | 待实施 |

实现排查位置：src/app/me/page.tsx及其考试目标、收藏、提醒和预审相关组件。普通用户自己的反馈、收藏和预审历史属于个人业务数据，采用收纳和按需展示，不迁至仅管理员可见；内部环境诊断仍按UXR-02管理。
