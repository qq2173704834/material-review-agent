## UXR-01 考试卡片间距与布局修正

- 优先级：P1；状态：本地验收通过；关联缺陷：BUG-039；关联原需求：PORT-01.A4、PORT-02.A1。
- 用户反馈：截图中相邻考试卡片边缘贴合、存在重叠观感，需要调整位置。
- 证据：[用户截图](assets/feedback/exam-card-overlap.png)。截图可确认卡片之间缺少清楚的留白，红框处边缘/圆角相互挤压；是否由卡片宽度、列间距、阴影或其他布局规则导致，实施时复现确认，不预先认定根因。
- 目标：卡片各自独立，标题、分类、状态和底部操作清晰可见；随可用宽度调整列数，保持现有卡片内容与操作。

| 条件      | 具体需求与验收标准                                                                                                                                        | 状态         |
| --------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------ |
| UXR-01.A1 | 调整卡片宽度与行列间距。桌面端卡片之间建议至少16px留白、移动端至少12px；相邻卡片边框与圆角不接触、不覆盖，阴影不形成重叠边框观感。                        | 本地验收通过 |
| UXR-01.A2 | 按容器宽度调整列数，窄屏自动减少列数或单列展示；在390、768、1280、1920px视口及浏览器125%/150%缩放下，卡片不重叠、不越出容器，不产生由卡片引起的横向滚动。 | 本地验收通过 |
| UXR-01.A3 | 使用长考试名称、长标题、多行摘要和不同状态文本核对：分类与状态不互相遮挡，文字留在卡片内；“查看详情”“关注目标”可见可点击，键盘焦点不被相邻卡片遮住。      | 本地验收通过 |
| UXR-01.A4 | 对截图所在考试列表及复用同类卡片的首页列表进行回归，检查单卡、多卡、跨行和筛选后布局；保存修正前后截图并人工核对用户标注区域，才能标记完成。              | 本地验收通过 |

实施建议：优先检查网格间距、卡片最小宽度、内容溢出和阴影；采用随容器变化的布局规则，避免仅固定移动某一张卡片。具体技术方案在复现后确定。

本条反馈作为PORT-01.A4学生走查发现的问题记录，当前不构成该项通过；修正后继续收集首页体验反馈。
