## UXR-31 从我的考试导入审查要求

优先级P1。关联UXR-25、PREP-01/09及PORT-11，复用个人考试目标、已保存公告与既有材料自查。

“之前已勾选的考试”按当前账号已保存的考试处理，优先列出“我的考试目标”；此前保存为收藏的考试公告在“已收藏公告”分组中选择，避免把目标和公告混成一份列表。入口名称采用“从我的考试导入”，位于“通知或要求原文”附近，与粘贴文本、公开网页、上传文件处于同一操作区。一次为当前任务选择一个适用考试/场次，不把无关考试要求自动合并。

| 条件      | 具体需求与验收标准                                                                                                                                                                                                                                                                                                             | 状态   |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------ |
| UXR-31.A1 | 提供“从我的考试导入”入口，可打开并搜索当前账号已保存的考试目标/收藏公告，显示考试名、地区、考期及关联公告，单选后预览。只列本人可访问记录，多场次必须明确选择；尚未保存考试时给出添加考试目标或浏览考试入口，取消选择不改变当前表单。                                                                                          | 待实施 |
| UXR-31.A2 | 确认前展示将导入的考试、适用场次和通知/要求原文摘要，确认后带入可追溯的公告来源、已收录原文及关联信息，减少重复粘贴。保留真实来源、版本及原文适用范围；目标未关联公告时可选择适用候选，无明确材料要求、公告仅有摘录、已撤回/停办或来源不可用时给出就近业务提示，允许手工补充。不得把考试名称、概况或模型猜测当作正式审查要求。 | 待实施 |
| UXR-31.A3 | 已有文本、网页或文件输入时先预览导入影响，明确确认替换并可取消，失败或切换来源不丢失原草稿。已有同目标材料任务时提供打开原任务的选择，重复点击或重试不悄悄创建重复任务；不因选中考试自动开启自动预审、运行模型、覆盖规则版本或修改历史结果。后续正式保存仍沿用原任务与权限流程。                                               | 待实施 |
| UXR-31.A4 | 后续核对目标与收藏两类入口、多目标/多场次、无关联/无要求、重复选择、已有输入、取消、失败重试及公告变化；手机和键盘可完成选择与预览，跨账号不能读取他人目标、收藏或任务。材料自查的上传、规则确认、证据与复检原流程仍可用；本轮登记不计功能验收。                                                                               | 待实施 |

现有个人目标已有材料准备入口及公告关联能力，本条解决通用新建页的来源选择问题；实现时复用现有能力，不能另建一份个人考试数据。目标收藏分组属于本次对“已勾选”的范围解释，后续用户若指定仅目标则相应收窄，不影响只做需求的边界。
