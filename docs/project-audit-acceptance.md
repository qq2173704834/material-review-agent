## 缺陷与回归证据

- BUG-047：删目标标签残留科目/阶段；旧构建复现，统一依赖规则后回归。
- BUG-048：无结果内重新查询保留原条件；旧恢复测试失败，改为真正清除后可找到已发布公告。
- BUG-049：仅搜索再取消导入也标记任务修改；旧浏览离开出现拦截，修复后取消不污染真实草稿。
- BUG-050：折叠学习偏好丢失未保存选择；旧构建复现，改为受控draft/baseline并覆盖失败与后台刷新。
- BUG-051：受控延迟回复清空期间输入的新草稿；旧构建复现，提交快照与修订号保护后通过。
- BUG-052：旧会话历史晚到覆盖最后选择；受控乱序旧构建复现，请求取消/序号保护后通过。
- 回归中新发现的助手Esc和手机发送按钮可见性问题属于AUD-06/08的同轮修复：发送按钮禁用后焦点可能落到面板外，Esc原只监听面板；手机长内容挤出操作。增加打开期间document级Esc监听及固定输入/可滚动内容区，保留原失败断言复测，不放宽可见性标准。
- 四六级筛选测试原失败是旧空态标题断言未随需求改动更新，实际筛选仍正确；更新标题断言并补零公告断言。
