# 考试信息平台与注册登录扩展需求

版本：1.1。日期：2026-11-13（Asia/Shanghai）。工程任务：ENG-024需求；用户已授权ENG-025—ENG-029开发，按工程证据分别验收。

后续方向（2026-11-14）：用户进一步提出考试信息首页、学习子页、卡通知识AI助手及个人中心自动预审，新增条件见[平台新需求](exam-learning-portal-requirements.md)与[统一待办](product-backlog.md)。本文件48条保留原版本/验收口径，不等于新增PORT56条已实现。

## 1. 用户要求与产品定位

用户提出两项扩展：一是将项目扩为收集国考、省考、大学英语四六级、计算机二级等考试信息的网站，让已有文件/资格材料预审成为其中一个模块；二是提供注册登录，用户注册并登录后才能使用功能。

建议产品定位为“考试信息与报考材料预审平台”（描述性名称，正式品牌未定）。主路径为：注册/登录 → 找到考试与具体考期/地区公告 → 查看时间和报考要求 → 收藏跟进或创建预审任务 → 上传材料 → 处理问题与复查 → 导出。原通用材料预审继续作为独立模块，仍可自行导入其他通知。

本文件将两项方向拆为12个功能组、48条验收条件；EXAM-01—EXAM-06为考试信息，AUTH-01—AUTH-05为注册登录，LINK-01为二者与已有审查的连接。状态以[新增平台验收](exam-platform-acceptance.md)逐项登记为准，不沿用旧功能通过记录。原始114条、OPT及UX的历史实现与人工待验收状态保留，新需求不借用旧通过记录。优先级和细节方案由本次需求设计提出，不等于用户已选择了某个认证服务、邮件供应商、采集网站或数据库。

## 3. 登录与信息开放范围

依用户要求，产品业务功能全部需要登录：考试目录、列表/搜索/详情/附件、个人收藏、预审任务、文件、报告及管理后台均检查身份；接口也执行相同限制。访客可访问产品介绍、注册、登录、验证/找回入口、必要静态资源与最小服务健康信息，不提供考试业务数据。官方站点的外部链接本身不受本产品登录控制。

若以后希望开放部分公告用于访客浏览或搜索引擎收录，需单独调整需求，本版不默认开放。注册和登录入口不能因登录保护本身被拦截造成循环。

## 4. 考试信息需求（EXAM）

### EXAM-01 考试分类与考期目录（P0）

- **EXAM-01.A1**：支持国考、各省公务员考试、大学英语四级、六级、全国计算机等级考试二级，类别可维护；每项明确名称、组织方、考试级别/科目及适用地区，避免把考试地点与招录地区混为一谈。
- **EXAM-01.A2**：同一考试按年份、考期/批次和地区形成独立记录；年度考试名、公告发布日期、实际笔试日期可以不同年，不能只按标题年份推断日期。
- **EXAM-01.A3**：地区支持全国和省级，必要时注明市/校级公告适用范围；全国统一公告与地方报名通知有关联且分别保存，不用全国日期覆盖地方安排。
- **EXAM-01.A4**：目录显示已接入类别、地区和数据覆盖；未接入/尚未发布/待核实分别显示，不能把没有采集到等同没有考试。首批按明确清单验收，不宣称已覆盖全国全部省份和年份。

### EXAM-02 公告列表、搜索与筛选（P0）

- **EXAM-02.A1**：登录后可按考试类型、地区、年份/考期和公告阶段筛选，支持关键词搜索，页面展示当前筛选及清除入口；刷新、后退保留可公开的筛选条件。
- **EXAM-02.A2**：列表至少包含标题、考试/考期、适用地区、公告类别、发布时间、来源和最近核查时间；公告类别区分招考/报名、补充更正、准考证、考试、成绩/资格复审等实际接入内容。
- **EXAM-02.A3**：报名状态仅按已确认的起止时间和时区计算；未知、延期/取消、系统报名通道状态未核实分别披露。“可报名”不是本站已经验证外站报名成功。
- **EXAM-02.A4**：有分页或明确加载边界，无结果/加载失败可重试且保留筛选；过期信息可查历史，不因报名结束从收藏和关联任务中消失。

### EXAM-03 公告详情、时间线与要求（P0）

- **EXAM-03.A1**：详情展示官方标题、组织方、考试/考期、适用地区、原文链接、发布时间/抓取时间/最近核查时间及附件来源；每项关键时间和资格摘要可追溯到具体原文段落或附件版本。
- **EXAM-03.A2**：时间线包括报名起止、缴费、准考证、笔试和后续已公布节点；缺少的日期显示未公布，只有日期无时分时说明精度，不编造23:59截止；统一按Asia/Shanghai展示并注明来源时区差异。
- **EXAM-03.A3**：按原文整理报考条件、所需材料、办理/报名入口及适用人群；年龄基准日、学历/学位取得截止、户籍、应届和岗位特定条件按原文保留，不能将一般条件套到所有岗位/地区。
- **EXAM-03.A4**：附件逐份展示获取及解析状态，链接失败/部分读取保留官方替代入口；摘要与官方原文有明确区分，AI摘要未经核对不能直接发布为官方规定或自动宣布用户符合资格。

### EXAM-04 来源接入、采集与管理（P0基础，P1扩源）

- **EXAM-04.A1**：仅对经配置的公开官方来源接入，登记域名/入口、覆盖类别/地区、负责人、更新方式和频率；实现前逐个核验真实网址与访问条件，不凭名称推测官方域名。
- **EXAM-04.A2**：支持管理员手工录入/粘贴/导入公告及适配器抓取列表、详情和直接附件；手工导入可先形成业务闭环，自动采集逐源启用，不能以手工数据假称自动采集成功。
- **EXAM-04.A3**：采集有去重键/内容摘要、有限并发、超时、重试、频率及退避；记录来源、成功/失败时间、覆盖和错误，保留上次有效内容。网络失败不清空公告、不刷新“最近成功核查时间”。
- **EXAM-04.A4**：自动更新由服务端受控调度执行，配置可启停并记录下一次计划/实际运行；不依赖用户打开网页。遵守站点访问约束，不绕过登录/验证码；沿用公开网络校验、逐次重定向检查和材料指令隔离。本站不代用户登录考试官网。

### EXAM-05 发布后台、变更与质量控制（P0）

- **EXAM-05.A1**：采集/人工录入先形成草稿，管理员预览原文、结构化字段和附件后发布；必需来源和适用范围缺失、日期相互矛盾时提示并阻止误发布，未确定字段允许空值并明确标注。
- **EXAM-05.A2**：相同公告重复采集不生成重复公开条目；更正/延期通知与原公告建立关系，保留发布版本、差异和处理记录，跨来源冲突不按抓取时间自动决定哪一条有效。
- **EXAM-05.A3**：公告支持发布、更新、撤回/下线及明确的考试取消/延期状态；撤回或下线不删除已关联审查的原始版本。已发布信息更新后向收藏/关联任务显示变更提示。
- **EXAM-05.A4**：后台显示各来源失效、待处理草稿和关键字段核查状态；记录操作者、时间和前后版本。普通用户不能采集任意内网URL、修改公告或调用管理接口。

### EXAM-06 个人考试工作台与收藏（P1，建议纳入首版闭环）

- **EXAM-06.A1**：用户可收藏/取消收藏具体考试考期或公告，收藏跨设备和重新登录保留；去重且仅当前账号可读写，不把浏览记录自动当作收藏。
- **EXAM-06.A2**：个人工作台汇总收藏考试、可确认的临近时间节点及关联预审任务，分别标识未知时间、已截止、公告变更和任务待复检；排序不掩盖来源未更新的情况。
- **EXAM-06.A3**：站内更新提示与官方实际变更版本关联，阅读/处理状态按用户保存；重复采集不重复提醒，没有新内容不能制造“新公告”。首批不默认发送短信、邮件或浏览器推送。
- **EXAM-06.A4**：支持以收藏进入详情或继续关联任务；公告撤回、任务删除或来源暂不可用时给出原因和有效入口，不创建重复任务、不将他人的任务带入个人列表。

## 5. 注册登录需求（AUTH）

### AUTH-01 注册与账号建立（P0）

- **AUTH-01.A1**：提供独立注册页、登录页及互相切换入口，字段错误就地关联；提交中防重复，服务失败保留非敏感输入，密码不写URL、日志或本地持久存储。
- **AUTH-01.A2**：采用用户已确认的用户名+密码，用户名3—32位、英文字母开头、可含字母数字下划线，不区分大小写且唯一；昵称非唯一。产生稳定用户ID及普通用户角色，不按昵称合并旧数据。
- **AUTH-01.A3**：注册成功生成8条高熵恢复码，仅本次展示并支持用户主动下载；数据库仅保存摘要。明确保存责任及丢失密码和全部恢复码后不能自助恢复的边界，不虚构邮箱验证。
- **AUTH-01.A4**：密码仅保存经维护的密码哈希库产生的不可逆哈希（方案须经运行环境验证），有长度/泄露弱密码策略、受限注册与发送频率；注册不能自行指定管理员/用户ID，重复请求不会创建多个账号。

### AUTH-02 登录、会话与强制访问控制（P0）

- **AUTH-02.A1**：登录成功建立服务端可撤销会话，使用HttpOnly Cookie、合理期限、生产HTTPS下Secure及SameSite设置；密码、会话令牌不暴露给前端脚本或写入日志，失效/禁用账号不能继续访问。
- **AUTH-02.A2**：所有业务页面和API都校验登录，覆盖考试查询、收藏、任务、文件/证据、报告、示例、模型操作和管理入口；匿名页面请求进入登录，匿名接口返回401，权限不足返回403或隐藏资源的404。
- **AUTH-02.A3**：登录后回到原本要访问的站内有效位置；拒绝外站及伪造回跳地址。支持退出并立即撤销当前会话；刷新/新标签页/返回不能恢复已退出访问权。
- **AUTH-02.A4**：会话过期显示重新登录入口，保留安全的站内返回位置；上传/长审查中到期的后续读取仍需登录，已保存执行可按归属恢复。重新登录不自动重提材料或收费模型调用；产品模式缺少认证配置或数据库故障时禁止降级为匿名local账号。

### AUTH-03 密码找回与账号安全设置（P0）

- **AUTH-03.A1**：提供用户名+恢复码的密码重设入口，不依赖邮箱；恢复码只存摘要，限频，错误统一提示，不记录密码及恢复码。
- **AUTH-03.A2**：正确恢复码重设后旧密码、全部旧恢复码及旧会话失效，同时仅本次展示新恢复码。失败不改密码，不能通过改用户ID替别人重设。
- **AUTH-03.A3**：当前用户可改昵称、密码和退出全部会话；改密码核验当前密码，同时更换恢复码并撤销全部会话。身份由服务端会话确定，不信任表单userId；本轮没有邮箱修改流程。
- **AUTH-03.A4**：注册、登录、找回和设置支持键盘及手机操作，具有密码显示切换、清晰错误与请求状态；不能仅用颜色表示错误，不用强制教程代替登录引导。

### AUTH-04 角色、资源隔离与权限（P0）

- **AUTH-04.A1**：至少区分普通用户和考试内容管理员；管理员通过受控初始化/授权建立，不能由第一个注册者自动获得。普通用户只能使用已发布考试信息，管理权限在服务端检查。
- **AUTH-04.A2**：任务、通知、材料原件/历史版本、解析片段、执行、追问、报告、副本包及收藏均按稳定用户ID隔离；猜ID、编码路径、旧链接、直接下载和后台任务不能跨账号读取或修改。
- **AUTH-04.A3**：沿用既有显式任务授权能力，所有者可向明确用户授权/撤销，范围与转授权规则清楚；注册不继承别人授权，内容管理员角色本身不获得所有私人材料的默认访问权。
- **AUTH-04.A4**：上传、审查、模型调用、下载及收藏/订阅配置有按账号的有限额度或速率控制，服务端校验；配额不足有明确说明且保留已有数据，不能靠创建多标签页绕过，不默认引入收费套餐。

### AUTH-05 历史迁移、管理与运行边界（P0）

- **AUTH-05.A1**：提供旧local/REVIEW_ACCESS_USERS数据迁移的预演清单和备份恢复方案，明确旧所有者、授权与新用户ID映射；迁移需操作者明确指定归属，不把所有旧任务交给第一个注册者，未映射数据保持隔离可恢复。
- **AUTH-05.A2**：用户/会话信息持久化，服务重启后账号与资源归属保留；数据库结构升级有版本、失败回滚/恢复验证，不通过重置用户数据库完成开发或演示。
- **AUTH-05.A3**：有受控账号禁用/恢复和必要安全事件记录，禁用立即撤销会话；删除/注销账号提供归属数据清单和确认，说明保留/删除范围，避免悬空授权和他人共享数据误删。日志不包含密码/令牌或材料正文。
- **AUTH-05.A4**：本地开发与正式产品配置区分；产品入口强制认证，无未配置用户就放行分支。旧测试身份仅在显式legacy-test且隔离e2e路径可用，不能作为正式登录旁路；上线前另验HTTPS、备份和多实例一致性。本轮不部署、不发送邮件。

## 6. 与已有材料预审的连接（LINK）

### LINK-01 从公告创建可追溯的报考材料预审（P0）

- **LINK-01.A1**：登录用户可从具体已发布公告点击“预审报考材料”，预填考试、地区、考期、来源链接与版本，并选择本次阶段（报名/资格复审等）；若规则按岗位/科目不同，要求选定具体对象或保留待确认，不默认对所有岗位适用。
- **LINK-01.A2**：用户明确选择后将本次可读取的官方通知和相关附件作为任务来源快照，显示成功/失败范围；不整站导入、不把他人材料作为来源。仍可新建不关联考试的通用任务，保留三阶段交互与既有多格式能力。
- **LINK-01.A3**：官方公告/附件后续更正时，关联任务提示来源已有新版并提供核对与明确采用入口；在更新来源前保留原执行依据，采用后受影响结果待复检。不能后台静默改写原任务、覆盖人工规则或自动重跑模型。
- **LINK-01.A4**：预审、报告与个人考试工作台可互相返回并显示所属考试/阶段/来源版本；五类判定、未执行与材料证据继续独立。材料预审结果只能表达输入范围内的符合/问题/待核实，不承诺报名成功、官方资格审核通过或替用户提交报名。

## 7. 页面与数据设计方向

| 页面/区域      | 主要内容                                     | 访问要求                   |
| -------------- | -------------------------------------------- | -------------------------- |
| 产品介绍       | 定位、能力说明、注册/登录入口                | 访客可用，无考试业务数据   |
| 注册/登录/找回 | 账号建立、身份验证和会话恢复                 | 访客可达，登录接口自身限频 |
| 考试信息中心   | 类别、地区/考期、公告搜索与筛选              | 已登录                     |
| 考试/公告详情  | 官方来源、时间线、条件、附件、收藏及预审入口 | 已登录                     |
| 个人工作台     | 收藏、站内更新、关联任务、继续预审           | 已登录且按用户隔离         |
| 材料预审       | 现有准备/审查/结果三视图                     | 所有者或已授权用户         |
| 账号设置       | 昵称、密码、恢复码/会话、注销                | 当前账号并按动作重新核验   |
| 内容后台       | 来源、采集、草稿审核、发布与变更             | 考试内容管理员             |

概念实体：User、Credential、Session、一次性验证/恢复令牌、角色/授权；ExamCategory、ExamEdition（考试+地区+考期）、Notice及NoticeVersion、Source及FetchRun、Attachment、Favorite/站内更新状态、ExamTaskLink。复用现有任务/来源/材料/执行版本，不把公共考试公告与私人材料放在同一个无归属内容表。

技术方向沿用Next.js/TypeScript/pnpm与现有存储接口。采用Node维护的原生scrypt及服务端随机会话，运行环境已验证；本轮不用邮件投递，不自制密码加密或将REVIEW_ACCESS_USERS包装成公开注册系统。现有SQLite可供单实例本地验证；是否使用PostgreSQL/对象存储/持久队列属于部署规模决策，未由用户指定，不能声称现有单实例已支持分布式生产运行。

## 9. 验收场景

| 场景                 | 关键路径与必须观察的结果                                                                                         |
| -------------------- | ---------------------------------------------------------------------------------------------------------------- |
| EP-AT01 注册门禁     | 访客打开考试/任务/下载URL→登录；API匿名401；注册保存恢复码→登录→安全返回原站内页面；退出后旧会话失效             |
| EP-AT02 账号恢复     | 用户名+正确/错误/已用恢复码重设，旧密码/旧码/旧会话失效；不依赖邮件                                              |
| EP-AT03 跨账号隔离   | A上传并检查，B猜ID/访问旧证据与ZIP均不可达；显式授权后按范围访问，撤销后拒绝；管理员不默认读私人材料             |
| EP-AT04 多考试多考期 | 全国地区目录、学生升学/语言/计算机/资格考试有合成结构样例；官方来源逐源核对；同考试不同考期/地区不混用时间或条件 |
| EP-AT05 采集与发布   | 已配置公开源采集→草稿→人工审核发布；重复采集去重，失败保留原文及成功核查时间；未知日期不编造                     |
| EP-AT06 更正与冲突   | 官方更正/延期→关联旧公告与差异→审核更新；跨来源冲突保持待核实；已关联任务原快照不变                              |
| EP-AT07 收藏与继续   | A收藏→重新登录/另一设备仍在，B不可见；收藏更新提示不重复，历史可查，任务删除/公告撤回有解释                      |
| EP-AT08 资格预审连接 | 指定考试/地区/考期/阶段/岗位→创建私有任务→上传审查→证据/修订/复检/报告；未知资格保留待确认                       |
| EP-AT09 新公告采用   | 已有任务收到公告变更提示→查看双方→明确采用新版→标待复检→复查；旧报告仍绑定旧来源和材料                           |
| EP-AT10 迁移与故障   | 预演旧归属映射、备份、迁移/恢复；注册竞态、禁用、认证配置缺失/服务重启均不造成匿名放行或旧数据被接管             |

所有新场景待实际执行。测试使用隔离账号/数据库与合成私人材料；公开来源接入须另记实际URL、核查时间与失败边界，模拟采集和受控邮件不能冒充线上真实集成。沿用桌面/手机、键盘、错误恢复与旧预审回归；此前UX人工验收待项仍保留。
