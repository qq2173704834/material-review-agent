# 当前用户与退出登录入口需求

日期：2026-11-15（Asia/Shanghai）。登记任务：ENG-081。用户要求在页面保留显示当前用户、能够退出登录的选项，随后明确“这轮也只做需求，不写代码”。本批新增UXR-29共1组4条验收条件，全部待实施。

## 展示与交互方案

在登录后的公共页面头部右侧保留一个轻量账号区，展示用户图标、当前用户名和“退出登录”按钮；与左侧页面导航形成清楚层级。手机同样保留账号区，空间不足时自然换行，长用户名省略显示且能获取完整名称，不挤压页面标题或导航。不将退出操作藏在账号设置页的操作选择框内。

优先显示本次会话的登录用户名，便于用户辨认当前账号；昵称可以在账号详情中补充，不用昵称单独替代用户名。点击用户信息可进入既有账号设置。退出采用直接按钮，显示真实忙碌和失败状态，不增加无必要的重复确认。

ENG-082补充（2026-11-15）：用户确认统一账号入口可用后，删除“我的考试/备考中心”主内容区重复的整行“当前登录用户名：… 昵称：… 账号设置与退出登录”。不保留空白占位或改写后的重复账号卡片；用户名仍由公共账号区显示，昵称及账号管理在账号设置中查看。先验证统一入口可用，再移除旧行。证据：[重复账号信息截图](assets/feedback/duplicate-account-summary.png)。这是UXR-29的细化，不新增验收编号。

## UXR-29 全站当前用户显示与快捷退出

优先级P1。复用已有认证、账号设置与会话撤销能力；关联UXR-04、UXR-24、UXR-28及PREP-01.A4。以下是新增前台入口要求，不把现有注册登录功能重复登记为未实现。

| 条件      | 具体需求与验收标准                                                                                                                                                                                                                                                                                                                                                       | 状态   |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------ |
| UXR-29.A1 | 首页、考试中心及详情、学习及资料详情、备考中心及子页、材料自查及任务页使用一致的账号区，展示当前会话的登录用户名，并可进入账号设置；统一入口可用后，删除个人页主内容区重复的用户名、昵称及“账号设置与退出登录”整行，不留占位。管理员使用同一账号区，维护入口仍按权限控制。加载或读取失败时不显示猜测账号、上次用户名或示例身份；未登录页面提供登录入口，不显示退出按钮。 | 待实施 |
| UXR-29.A2 | 账号区提供可直接操作的“退出登录”按钮，复用服务端撤销当前会话；请求中显示“退出中…”并防重复提交，成功后返回登录页。失败时保留真实登录状态，显示简短错误并可重试，不先宣称退出成功。退出不删除已保存的目标、计划、收藏、材料或历史记录，“退出全部登录”继续留在账号设置中。                                                                                                  | 待实施 |
| UXR-29.A3 | 用户名来自当前会话，昵称修改和重新登录后按最新身份显示；退出、会话失效或换号后，账号区与页面私有内容一致更新，清除上一账号的前端展示状态。退出后刷新或浏览器后退不能重新取得受保护数据，其他标签页重新获得焦点或发起请求时也要核对失效会话；A退出再登录B不得闪现A的用户名、目标或材料。                                                                                  | 待实施 |
| UXR-29.A4 | 桌面与手机入口均容易找到，用户名和退出按钮有清楚的主次及间距；320/390/768/1280px与125%/150%缩放下检查长用户名、忙碌和错误提示，无遮挡、重叠或横向溢出。键盘可访问用户信息和退出按钮，图标有文字或辅助名称，焦点清晰。覆盖登录前后、跨页、退出成功/失败、会话过期、双账号切换及多标签页回归后才更新验收状态。                                                             | 待实施 |

## 现状与后续实施顺序

静态检查发现公共导航已有“账号设置”入口，个人页提供账号设置与退出的入口，账号表单和认证接口已有退出当前/全部会话的能力。公共页面头部尚未提供本需求所述的用户名与直接退出组合。当前没有进行运行复现，不新增BUG编号，也不声称身份错误或退出接口故障。

后续先核对公共布局覆盖范围与身份读取，再接入现有退出能力，最后验证退出失败、会话失效及换号的展示一致性。具体实现与测试待后续开发授权；不在本轮改组件、接口、样式、运行配置或真实用户数据。

旧行移除验收：在桌面与手机的个人目标页、收藏等个人子标签确认重复区域已删除且间距自然；公共账号区仍展示正确用户，可进入账号设置并退出。不能为删除重复内容而撤掉唯一可用入口，或修改此前修复的账号数据隔离。

本批4条与原UXR-01—28的112条分别保留状态，UXR累计29组116条；PREP48条、EXP/PORT88条及原BUG记录不变，不直接相加为独立功能数。
