# 未选考期状态与日期同步修复

日期：2026-11-15，ENG-096 / BUG-056。

用户截图中大学英语四级目标为“待确认考期”，却在日程中统一显示“考试时间待公布”。代码确认：未选场次的目标不自动匹配某一份公告，该限制用于避免错用上半年/下半年、地区或其他场次日期；问题在于把个人尚未选择错误表达成了考试主办方尚未公布，而且没有直接选择入口。

只读检查本地已发布公共公告，当前存有“2026年下半年全国大学英语四、六级考试报名工作启动”：笔试2026-12-12，准考证2026-12-01 09:00（北京时间）。本轮未重新抓取官网，不将本地快照当作今日外部核验；未查询账号、私人目标或密钥，也未修改现用数据。

## 修复

- 日程分别表达“尚未选择考期”“尚未关联考试公告”“时间待公布”，仅来源缺少日期时使用最后一种文案。目标列表与准备概览同步表达。
- 未关联目标的日程卡提供“选择考期”或“关联考试公告”，直接打开本人对应目标编辑区。选择已收录公告并保存后返回原目标日程。
- 保存继续复用原目标和来源关联逻辑，自动读取所选公告的日期，不要求手填已存在的日期；保留个人学习设置和进度。不自动替用户选择考期，不新增重复目标。
- 返回地址按既有站内白名单检查，目标只从当前账号列表解析；已关联但未给日期的卡片仍指向实际来源。
