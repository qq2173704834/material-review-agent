## UXR-12 目标与日程同步及时间未定占位

优先级 P1，关联 BUG-041。日程需要呈现用户已添加的考试，不因缺少可排序日期而完全消失。

| 条件      | 具体需求与验收标准                                                                                                                                                                                         | 状态   |
| --------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| UXR-12.A1 | 新增或编辑备考中目标成功后，同页考试日程立即更新，无需手动刷新或再次收藏。没有日期或尚未关联公告时也显示对应考试目标，标记“时间待公布”或“待确认考期”。                                                     | 待实施 |
| UXR-12.A2 | 有日期的节点按日期排序，未定项目放在日程内独立的“时间待定”区域；日期已知但超出未来30天的目标可在“后续安排”查看，不能被标成未知。一个考试多节点有明确报名/考试/成绩标签，目标与收藏指向同一公告时避免重复。 | 待实施 |
| UXR-12.A3 | 只有既无可展示的关注/目标项目也无日程节点时显示总体空态；有未定项目时不再显示“近期暂无考试安排”作为全部内容。后续获得可用日期后，待定项转入相应日期区域，不残留重复占位。                                  | 待实施 |
| UXR-12.A4 | 编辑考试类别/地区/考期、暂停、归档和清除目标后同步更新；暂停/归档不再触发活动提醒，可按状态查看。清除仅移除该目标贡献，仍收藏或被其他目标引用的公告日程保留；不影响他人账号及历史预审任务。                | 待实施 |
