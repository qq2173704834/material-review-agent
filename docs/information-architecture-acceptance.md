## 实际交付

主导航为首页、考试中心、校园通知、学习资源、我的备考。个人区按考试目标、我的日程、学习记录拆成独立页面，账号及退出入口保留。首页默认最多6个考试、3条本校通知、3个本人事项；未知日期收纳到待公布入口。

统一日程复用目标、收藏及校园私人事项；公共日期以稳定来源节点投影，个人完成和手填日期单独按用户保存。列表和月历共用四类标签，保留逾期待办、完成恢复、通知导入预览、部分节点选择、重复加入去重和并发保护。来源更正或撤回后停止旧倒计时，保留手填值供确认。目标归档保留学习和材料历史。

材料自查收纳到目标、申请事项和个人工具，仍保留独立任务、证据与报告。校园来源更新会让旧结果待复检；学习和助手沿用原对象、个人授权与草稿预览机制，返回链接适配新页面。路由和数据兼容详见[information-architecture-migration.md](information-architecture-migration.md)。

## 用户走查

启动`pnpm dev`后，用测试账号登录：

1. 从考试中心找四级，加入备考，在考试目标查看日期摘要，进入我的日程。
2. 从校园通知选择学校，阅读一条通知，选择需要的节点，预览后加入日程。
3. 在我的日程导入作业或手动新增，切换四类标签和日历，试完成、恢复与调整日期。
4. 查看首页本人摘要是否同步，查看待公布安排是否容易找到。
5. 在目标里继续学习并查看学习记录；有报名/申请材料要求时进入材料自查，再返回原上下文。
