# 学生备考中心与可视化需求

版本：1.0。日期：2026-11-15（Asia/Shanghai）。登记任务：ENG-079。

用户认可备考中心的可交互概念稿，并要求“细化成需求”。本批登记 PREP-01—12 共12组48条验收条件：核心阶段10组40条，后续数据增强阶段2组8条，当前全部待实施。本轮仅整理需求，不开始应用编码、数据迁移或模型调用；概念稿的本地交互检查不属于应用功能验收。

## 产品目标与页面组织

备考中心围绕“今天做什么、重要日期是什么、下一步学什么、材料还缺什么”组织个人备考过程。面向在校学生，沿用用户名与密码认证、现有考试目录、学习资源、知识AI助手、个人目标和材料审查引擎。

考试信息首页继续承担近期考试发现、报名状态与每日内容更新；备考中心承接“我的考试”的个人备考主区，不另外建立一份个人目标，也不直接将登录默认首页改为学习仪表盘。账号、隐私、收藏及历史记录保留清楚的入口。正式品牌名称和最终URL未在本轮指定。

| 页面       | 主要视觉形式                                             | 核心操作                               | 复用能力                     |
| ---------- | -------------------------------------------------------- | -------------------------------------- | ---------------------------- |
| 备考概览   | 当前目标卡、关键日期倒计时、今日任务、近期节点与材料摘要 | 继续任务、切换目标、进入日历/路线/自查 | 个人目标、考试安排、预审结果 |
| 考试日历   | 桌面月历与节点详情；手机近期日程列表；时间待定区域       | 切换月份、选择日期、进入相关准备步骤   | 公告场次及个人日程           |
| 备考路线   | 阶段节点、任务完成进度和阶段资源                         | 切换阶段、编辑与勾选任务、查看资料     | 目标、学习资源、个人进度     |
| 材料自查   | 材料清单、状态、原文件/文本证据与问题定位                | 上传/替换、查看问题、整改、复检、报告  | 原审查流程及版本证据         |
| AI学习计划 | 简短需求输入、周计划、每日任务与时间分配                 | 生成建议、调整、预览并加入计划         | 既有助手、模型配置和知识来源 |

学习热力图、能力雷达图和成绩变化曲线作为后续数据增强，不挤占核心页面首屏。所有图表都需有可理解的文字值和详情入口。

## 范围、统计与已有待办的关系

- PREP独立于原EXP/PORT88条、原始114条和UXR112条。PREP描述新的个人备考场景；共同依赖只实现一次，各自按原条件验收，不将旧通过记录直接复制为新场景通过。
- UXR-09—13和BUG-040—042继续负责目标操作、保存反馈、日程缺项与场次日期一致；PREP不另开同现象BUG。UXR-14—28继续负责筛选、文案、资料操作、自查定位和返回上下文。
- 核心阶段不新增考试报名代办、外发通知、题库考试引擎、自动判分或分数预测；能力图可以使用用户明确录入的自测记录，完整在线练习系统需另行明确。
- 可交互概念稿仅作布局和交互参考。演示中的四级日期、报名节点、照片尺寸、四份材料和任务比例不写入真实默认数据，不视为真实四级政策；正式材料清单随适用公告确定。
- 清爽校园风格与柔和紫色作为视觉方向，具体像素、装饰文案和卡片数量不冻结为产品规则。普通学生界面不加入工程编号、模型配置、采集诊断或长篇免责说明；必要的未知、预计、模拟和未执行状态用简短业务语言说明。

## 跨页面数据与交互约定

以下说明上述条件共用的语义，具体表结构、API和图表库留待实施设计，不新增强制技术选型：

- 目标以现有稳定目标ID关联考试类别、具体场次和用户归属；官方节点保存公告/版本、节点类型、时区与日期精度，个人任务日期另存，不覆盖官方时间。
- 路线、阶段、任务和计划草稿具有稳定标识；任务区分预计时长、明确记录的实际时长、安排日期与实际完成日期。进度分母只取当前计划内有效任务，移除任务后的统计变化可解释。
- AI生成草稿、采用后的个人计划及其修订分开保存；重复请求/采用幂等，冲突写入有明确处理。内容及私有记录沿用现有服务端认证与用户隔离，不进入公共知识库。
- 材料摘要来源于现有任务、执行快照和文件/规则版本；自测记录单独保存来源与评分体系，学习任务完成比例、自测成绩和材料判定不互相代替。
- 个人暂停/归档目标不参与活动提醒，历史保留可查看；清除目标、删除任务和删除自测记录遵循对应确认与保留范围，不级联删除其他目标、收藏或历史预审。
- 统一采用UXR的保存反馈、筛选、资料主入口和返回上下文规则；业务字段必须持久化，概念稿的浏览器局部状态不能作为正式实现。
