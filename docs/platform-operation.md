# 学生考试平台本地操作与恢复

日期：2026-11-13。适用于当前单进程本地开发版，不是生产部署说明。

## 启动与登录

在 CMD 执行：

```bat
cd /d E:\Projects\material-review-agent
pnpm dev
```

打开 http://127.0.0.1:3000/register，以用户名和至少12位密码注册，保存本次显示的8条恢复码。然后登录，默认进入 `/exams`。昵称不作为登录标识。忘记密码凭用户名及任意一条恢复码重设，全部旧码和登录立即失效，须保存新码。

`/exams` 是考试中心，`/me` 是收藏与关联任务，`/` 保留独立材料预审，`/account` 管理账号。未登录不能查询业务数据或下载材料。旧 `REVIEW_ACCESS_USERS` 不再作为产品登录入口。

## 本地管理员

先正常注册账号，再在项目目录运行预演，确认后加 `--apply`：

```bat
pnpm platform:admin accounts
pnpm platform:admin role --username YOUR_USERNAME --role admin
pnpm platform:admin role --username YOUR_USERNAME --role admin --apply
```

授权后旧会话被撤销，重新登录再进入 `/admin/exams`。首注册者没有管理员权限；内容管理员也不能默认读取他人的私人材料。禁用/恢复同样需要显式操作：

```bat
pnpm platform:admin disable --username YOUR_USERNAME --apply
pnpm platform:admin enable --username YOUR_USERNAME --apply
```

## 公告采集与审核

初始官方来源均未启用定时采集。进入后台可先“采集一次”，查看逐源记录和草稿。核对标题、类别、考期、适用地区、组织方、原文及日期引用，再发布。日期未知留空；只有日期的公告不会编造时分。采集可能含待分类信息，不能将可访问入口等同全部公告已覆盖。

每次来源最多取8条候选，详情逐条请求，12秒单请求超时、4MiB网络读取上限，失败记录及保留历史数据。相同内容去重，更改形成新草稿，已发布版保持到管理员再次发布。来源首页改版或脚本渲染可能需调整适配器；不绕过验证码或证书错误。

启用后服务端每分钟检查到期来源，默认6小时，可设1—168小时，失败指数退避，上限48小时；租约避免多次同时采集。仅本站进程运行时执行，不依赖网页打开；停止服务期间不运行，重启后检查到期任务。`EXAM_SCHEDULER=off` 可显式关闭调度。SQLite单实例开发版不承诺分布式调度。

面向学生的全国目录含31省级机构官方链接，其中本次18个HTTPS入口可访问并登记为可配置来源，13个访问失败保留官方查询入口；港澳台仅有地区筛选，尚未接入机构。入口可达、详情采集成功、公告审核发布为三个独立状态，详情覆盖以实际采集记录为准。

## 公告与预审

公告详情“用此公告预审材料”需明确阶段和具体岗位/科目（不明确填待确认），保存公告正文版本。附件逐份显示链接和读取状态；创建后在任务来源中发现并明确导入官方附件，不能把尚未读取附件当审查依据。相同用户、公告、阶段与对象复用现有任务。

官方更新后收藏和关联任务提示变化；在 `/me` 先核对新旧公告，再明确采用新版作为补充来源。旧来源和执行不覆盖，当前规则需要重新核对提取，旧结果按来源变化待复检；不自动调用收费模型。五类判定和证据规则继续沿用。

## 旧数据迁移、备份与恢复

新注册不会获得旧任务。先注册目标账号，再预演明确映射，例如旧 `local` 或 `legacy-unassigned`：

```bat
pnpm platform:admin migrate --from local --to YOUR_USERNAME
pnpm platform:admin migrate --from local --to YOUR_USERNAME --apply
```

预演列出涉及任务与授权；实际迁移前用SQLite在线backup API保存两个数据库和迁移清单至 `.local-data/backups/时间-随机ID/`，之后在事务中迁移该身份的所有者和明确授权。其他旧身份不变，按需逐个映射。可通过 `--data-dir PATH` 对独立目录操作。不要把不明归属整体迁给首个用户。

手工备份运行 `pnpm platform:admin backup`。数据库与 `materials/` 原件应在停止服务后作为同一恢复点保管，外置备份也须保护私人材料。恢复时先停止本站所有服务，另存当前整个数据目录以便回退；将选择的备份中 `platform.sqlite`、`reviews.sqlite` 和同一恢复点材料放回新的恢复目录，不复制旧的 `-wal` / `-shm` 文件。用 `REVIEW_DATA_DIR` 指向恢复目录启动，核对账户与任务归属。先在独立目录验证，再替换正式数据；不得对运行中数据库直接覆盖。自动测试验证了迁移前预演、备份完整性和从备份恢复到独立数据库，不代表已替用户恢复真实数据。

账号注销需再次输入密码与确认语句，先拒绝仍在运行的审查，再删除自己任务及原件、恢复码、会话及账号，撤销该账号在他人任务中的授权。他人的任务保留；安全事件只记动作和稳定ID，不保存秘密或材料正文。删除已下载到外部的副本需要用户自己管理。

## 测试

`pnpm test:platform` 使用独立platform-e2e数据库验证真实账号机制，`pnpm test:sources` 使用独立source-e2e目录真实访问四六级、计算机等级、教资、研招网等公开源，日语入口保留失败核验。后者依赖网络，产生草稿而不发布，不调用模型。旧 `test:e2e`、`test:model`、`test:access` 保留显式隔离的旧测试适配器，用于旧材料能力回归，不能当新账号验收。
