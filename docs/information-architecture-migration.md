# 功能分区实施与兼容清单

日期：2026-11-15。ENG-095实施ORG-01—10。本文件描述本批实际路由和数据处理；验收结果另见[information-architecture-acceptance.md](information-architecture-acceptance.md)。

## 页面与旧入口映射

| 原入口/能力                            | 当前去向                         | 兼容方式                                                              |
| -------------------------------------- | -------------------------------- | --------------------------------------------------------------------- |
| `/`                                    | 首页                             | 保留状态标签和展示设置；默认6个考试，校园/私人摘要分别最多3项         |
| `/exams`及公告详情                     | 考试中心                         | 原URL与内容ID保持；私人考试/作业不写入公共目录                        |
| `/campus`                              | 校园通知                         | 原选校、已读、收藏、部门分类与公开通知保留；只承载公开消息            |
| `/campus?proposal=…&edit=…`            | `/me/schedule?proposal=…&edit=…` | 服务端跳转，保留原提案和事项ID；旧助手会话链接可继续使用              |
| `/campus?view=schedule`                | `/me/schedule`                   | 转到独立日程                                                          |
| `/me`及`?view=overview`                | 我的备考→考试目标                | 默认显示目标；收藏/反馈/材料记录收纳到个人工具                        |
| `/me/schedule`                         | 我的备考→我的日程                | 新独立页面；支持目标筛选、四类标签、列表/日历、完成恢复和时间待定分组 |
| `/me/preparation?goal=…`               | 目标详情                         | 保留路线、学习任务、AI计划和材料准备；只显示本目标日期摘要            |
| `/me/preparation?goal=…&view=calendar` | `/me/schedule?goal=…`            | 兼容跳转，取消第二套独立日历                                          |
| `/me/preparation?goal=…&view=records`  | `/me/records?goal=…`             | 学习记录独立页面，保留目标选择与真实统计                              |
| `/me/goals/:id`                        | 对应目标材料准备                 | 原URL保留；在个人目标内可达                                           |
| `/tasks`和`/tasks/:id`                 | 个人工具/相关事项的材料自查      | 原任务和证据不移动，主导航选择我的备考，保留历史独立任务              |
| `/learn`及资料详情                     | 学习资源                         | 原资料、收藏、阅读状态保持；支持返回目标/日程上下文                   |

主导航只有首页、考试中心、校园通知、学习资源、我的备考五项。管理员入口仍按账号权限展示。我的备考三个子页均有独立地址，所有页面保留统一账号与退出入口。

## 数据处理

1. `student_goals`、`preparation_states`、`campus_states`、收藏/阅读记录和材料数据库保持原有归属与ID。没有把公共通知或考试日期批量复制为私人事项。
2. 公共考试时间通过`personal-schedule.ts`投影，节点ID由公告ID、节点标签和同标签序号构成，不含日期；目标和收藏关联同一公告时复用节点。已有关注提醒的公开范围保留，取消收藏与归档目标各自生效。
3. 新增`personal_schedule_nodes`保存当前用户对公共节点的完成状态、手填日期及确认的来源日期。复合主键为用户ID/节点ID，按节点版本和来源值拒绝旧修改；不影响公共报名状态。表通过幂等DDL创建，无需重写旧表或清空旧记录。
4. 私人事项继续保存在`campus_states.events`。新导入的公开通知节点增加可选`sourceNodeKey`，重复确认同一节点保留原事项。旧记录无此字段仍可读取和保存，沿用原有标题/课程/学期/来源去重。
5. 未知日期不补造；仅日期不补23:59；时区按北京时间计算。来源变化后保留原填写，并停用旧倒计时，用户核对后才能重新采用。全国考试未知转已知时沿用目标关联，原手填值仍可核对。
6. 页面归档操作使用已有目标保存接口，保留学习与材料历史；独立材料任务仍可从个人工具进入。全站返回前台时刷新服务端投影，变更通过无私人内容的跨标签页信号同步；编辑基准版本保留，冲突时不自动覆盖输入。
7. 校园材料任务继续保存原通知快照。通知更新/撤回后，任务、结果与报告均通过既有有效性标注保留待复检；原任务不被新任务覆盖。私人日程更正的确认不等于材料审查通过。
