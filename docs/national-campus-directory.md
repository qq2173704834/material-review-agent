# 全国学校名称目录扩充

日期：2026-11-15（Asia/Shanghai），ENG-098，落实CAMP-01的选校与名称目录覆盖。

用户指出原3所上海试点学校不足以服务其他学校学生。本轮将名称目录扩充到教育部公开的全国高校名单，并明确学校可选范围与站内通知覆盖的区别。

后续ENG-099已扩充通知至9校11来源85条并修正空态，见[通知内容与覆盖修复](campus-notice-coverage.md)。下文3校5来源及页面提示为ENG-098交付时的历史快照。

## 数据依据与范围

2026-11-15实际读取教育部[全国高等学校名单](https://www.moe.gov.cn/jyb_xxgk/s5743/s5744/202606/t20260618_1441074.html)及两份附件。该页说明截至2026-06-17，全国3196所高校：普通2952所（本科1412、高职专科1540）、成人244。本名单不含港澳台地区高校，覆盖内地31个省级地区。

- [全国普通高等学校名单附件](https://www.moe.gov.cn/jyb_xxgk/s5743/s5744/202606/W020260618416094865984.xls)
- [全国成人高等学校名单附件](https://www.moe.gov.cn/jyb_xxgk/s5743/s5744/202606/W020260618307096079727.xls)

运行数据为`src/domain/campus-directory.json`，保存来源、名单日期、读取日期、附件SHA256、数量及各校名称/学校标识码/地区/层次。原表没有官网列，因此不猜测或生成各校官网。下载原件仅保存在忽略的work目录。

可复现导入：安装离线导入依赖Python xlrd后，下载上述附件，执行`python scripts/import-campus-directory.py regular.xls adult.xls`。脚本校验3196条及唯一学校标识码，生成运行数据，不读取应用数据库；后续名单变化应另行核对来源和数量，不能用旧硬编码校验掩盖变更。应用运行不依赖Python或网络下载。

## 页面与数据行为

1. 所有名单学校可在“我的学校”按全名、片段或常用简称查找，也可选择省级地区缩小范围。“北大”“浙大”等支持已登记别名；“南大”“山大”等有歧义时保留多个结果，用户明确选择。
2. 学校下拉最多展示40条匹配（另保留当前已选项），申请面板最多8条，并显示总匹配量及继续输入提示，避免在页面生成数千选项。
3. 原上海第二工业大学、上海师范大学、上海工程技术大学保持sspu/shnu/sues原ID，原学校偏好、私人事项、收藏和通知关系不需要迁移。其他学校使用moe加教育部学校标识码构成稳定ID，保存接口沿用目录校验与账号隔离。
4. 名称目录3196所、已接通知学校仍3所、已配置通知来源仍5个；选择未接通学校可保存，通知区域和首页说明“通知正在整理”，提供个人日程/私人导入去处。收录学校不等于已采集该校通知，不显示成“本校暂无新通知”，不自动触发采集或编造消息。
5. 申请面板与主选校使用同一搜索逻辑，已收录学校可直接选择，真正不在目录中的学校仍可仅凭名称申请，官网继续选填。
