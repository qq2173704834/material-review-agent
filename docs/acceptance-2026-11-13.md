## 实际验证

- `pnpm check`：ESLint、TypeScript、Prettier 与 5 项单元测试通过。
- `pnpm build`：Next.js 生产构建通过。
- `pnpm test:e2e --workers=2`：桌面/移动共 98 项通过；实际 PDF/OCR、版本、原件、检索、增量复检、工作台与打印 PDF 均包含其中。
- `pnpm test:model --workers=2`：受控兼容接口 26 项通过，覆盖伪造证据/来源、模型错误、取消等。该套结果不作为真实模型效果指标。
- `node tests/scripts/live-acceptance.mjs`：DeepSeek 实际调用，6 组复合场景通过，包括必交/选交/适用性、总页数、冲突、空标题、内容匹配、跨文件不一致、修订复检、部分解析与二选一。
- `node scripts/evaluate-quality.mjs`：实际 `deepseek-flash`，20/20 任务完成，60/60 参考判定吻合，详见 quality-evaluation.md。数据是固定合成参考集。
- `node tests/scripts/live-attachments.mjs`：真实公开 W3C 网页 → 发现直接 PDF → 下载解析 → 保存 URL/时间 → 重复导入复用 → 跨任务拒绝，全部通过。外网可用性可能随网站变化。
- 已查看桌面/移动工作台截图，历史文件名、版本、引用高亮、内容与操作可读，无整体横向溢出。截图位于忽略的 test-results/。

各套测试使用独立数据目录，不清空用户 `.local-data/`。真实评估仅使用合成材料；真实附件使用公开 W3C 测试文件。密钥未进入测试资产、报告或 Git。

## 修复的真实缺陷

- BUG-003：Tesseract 7 语言初始化参数不正确；改用本地中英训练数据目录与语言名，实际 OCR 通过。底层偶有辅助语言/字体告警，复杂材料需人工核对。
- BUG-004：真实规则“总页数不得超过”未进入上限比较；扩充解析并增加边界回归，真实两页 PDF 复测通过。
- BUG-005：模型将“适用于所有材料”“需要语义判断”及未要求的规格误当条件/歧义；明确字段契约并用实际模型复测。
- BUG-006：模型偶尔先输出 JSON Schema 再输出业务 JSON；明确 schema 为校验说明，仍严格校验唯一业务对象，不通过截取尾部掩盖非法输出。
- BUG-007：附件来源类型为 file 时未持久化 URL，重复导入去重失效；保存文件来源 URL/获取时间，真实附件重复复用验收通过。
- BUG-008：ESLint 扫描正在变化的测试数据库目录，测试删除文件时偶发 ENOENT；将 `.local-data/` 纳入全局忽略，不扫描运行数据。

- BUG-009：材料上传区用材料版本作整个组件的 key，刷新时会清空本批上传反馈；改为任务级稳定组件并同步服务端材料状态，保留批次结果；原有导入/恢复场景和完整回归验证。
- 主编辑器新增未保存提醒，捕获链接导航及 Chromium 后退，刷新使用浏览器原生提醒；同任务筛选/锚点不触发。取消离开保留输入，保存成功清除提醒；不支持 Navigation API 的浏览器仅有链接/刷新兜底。
- 基础次要文字色由 #687386 调深至 #5d687b，以满足浅灰背景上普通文字的 4.5:1 对比度；这不等同全面无障碍审计。
